FOLK Icon Pack

Using it with the Folk Stud UI skill: leave this zip in Downloads, Desktop or Documents. You do not need to unzip it.
Then ask Claude things like "use icons from my icon pack". It finds them, uploads only what it uses, and puts them in your menus.

Picking by eye: unzip it and open "Browse all icons.html".

Licences: "Ranks" and "Keyboard Keys" are by RhosGFX, free under CC0 (see their License files).
The other folders came with no licence. Source catalog: https://noobiscool0.github.io/UI-Icon-Pack-Catalog/
Check it before using them in a released game.
