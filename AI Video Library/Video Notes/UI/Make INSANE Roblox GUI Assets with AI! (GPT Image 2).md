# Make INSANE Roblox GUI Assets with AI! (GPT Image 2)

Back to [[00 Start Here]] · [[00 Video Notes Index]]

## TL;DR
Generate reusable Roblox GUI elements (a sub button and a panel background) with an AI image generator, upscale to 2K, remove the background, download max quality, and compress for game use. Sponsored by an editing platform; the prompts themselves are behind the creator's "Roblox Bible".

## Tools and setup
- Erase Remove (sponsor, spelling from captions "Erase Remove"; AI photo editing platform with multiple generators under one subscription), link in description.
- AI image generator inside it ("GPT image tool"; multiple other generators available).
- Quick actions > Upscale; Background remover (batch background remover also exists).
- Creator's "Roblox Bible" holds prompts: the GUI with AI elements section, with a prompt for individual GUI elements.
- Cost: under 20 credits for both assets at maximum quality.

## Step-by-step
1. [00:00] Edit tools > AI image generator.
2. [00:00] Take the "individual GUI elements" prompt from the Roblox Bible (not reproduced in the video).
3. [01:00] Generate a premium Roblox sub button for a modern simulator (no reference image used). Queue a second generation: a Roblox GUI panel background. Generations run concurrently.
4. [02:00] Quick actions > Upscale. Pick 2K ("more than enough"). Apply to enhance. Do the same for the background.
5. [03:02] Go to the background remover (batch remover for multiple images).
6. [04:03] Download the upscaled button, upload to the remover. Optionally use brush size to paint parts it missed.
7. [04:03] Download: free preview version or maximum version; choose maximum, then compress to make it game ready.
8. [05:04] Repeat for the panel background (removed in one shot, no re-prompt).
9. [05:04] Total time roughly 5 minutes or less; assets are transparent, ready to import.

## Prompts and skills used
The actual prompts are not shown; they are in the creator's "Roblox Bible" (link in description). Request described: "premium Roblox sub button for my modern simulator game" and "Roblox GUI panel background".

## Gotchas and fixes
- Background removal on UI assets is described as the hardest part; fix leftovers with the brush tool.
- Upscaling gives clearer results; subtle but visible.
- Compress before putting in game.

## Use it in our games
- Generate a consistent set of simulator buttons and panels this way, then use them as ImageButton and ImageLabel assets (inferred).
- Upscale to 2K but compress before upload, to keep Roblox asset size sensible (inferred).
- Any image generator plus background remover works if you do not use this sponsor (inferred).
