# I Built a Roblox Pet RPG with Claude Opus 4 MCP + Roblox Studio MCP (Full Tutorial)

Back to [[00 Start Here]] · [[00 Video Notes Index]]

## TL;DR
Full pipeline for pets: ChatGPT reference art, then Meshy AI image-to-3D (multi-view, remesh, texture), then Blender with Claude via Blender MCP for rigging and animation, FBX import into Studio, then Claude plus Roblox Studio MCP for the shop, pet follow/combat AI, enemies and VFX.

## Tools and setup
- ChatGPT (image generation: pet references and shop icons).
- Meshy AI (browser): image to 3D, multi-view, remesh, texture, healing-brush texture edit.
- Blender with Blender MCP connected to Claude (separate setup video in description).
- Claude Opus 4 with Roblox Studio MCP; a Claude Project holding the game design document.
- Roblox Studio 3D Importer, Toolbox (free simulator shop model, "aura NPC" lightning particle asset, flipbook particles), Asset Manager.

## Step-by-step
1. [00:11] Upload photos of your own dog to ChatGPT: "Create image reference for my low poly cartoon style dog so I can generate 3D model for it." It sat; follow up: "I want to rig this model, so please make him stand with four legs, not sit."
2. [01:11] Screen-capture the multi-view sheet into separate front, side and angle images (aim for four directions).
3. [01:11] Meshy: upload main image, model type Standard (not low poly on first generation), enable multi-view and add the other images, Generate.
4. [02:12] First result about 250,000 triangles. Click Remesh, choose Adaptive with low quality reduction, topology Quads (easier in Blender). Result about 3,000 triangles.
5. [02:12] Click Texture to generate textures; download as FBX.
6. [03:13] Blender: import FBX, confirm Blender MCP is connected. Prompt: "Nice, I want to rig this dog model. Please add skeletons to it first." Then: "Nice, please continue parent the mesh to the armature and automatic weights."
7. [03:13] Ask Claude for animations: idle (breathing, tail wag), walk cycle (fix loop where last frame differs from first), a longer idle ("stand in idle state sometime and sometimes sit down and looks around"), then add IK bones to all four legs to fix foot alignment. Switch animations via Dope Sheet then Action Editor.
8. [04:14] Parrot: ChatGPT "Design for me a 3D parrot in cartoon style with multiple views and easy for generate rig model in Meshy AI." Mistake: wings drawn too close to the body, causing rigging deformation.
9. [05:14] Meshy parrot: Standard, texture, remesh with Fixed polygon count (mistake, black patches); repair with Edit Texture, Healing Brush, save, re-download FBX.
10. [06:14] Blender: Claude makes skeleton; reposition wing bones, auto weights, IK for legs and wings; separate the wings into their own mesh; generate idle and flying animations.
11. [07:14] Export FBX with the settings below; import in Studio via 3D Importer, rig type Custom, load animations from the FBX. Repeat for dog.
12. [08:34] Publish all animations to Roblox and note the animation IDs. Import the Island Arena level, scale and position pets, use a free toolbox simulator shop.
13. [08:34] Water: prompt "The water still does not display same texture as editor view. Can you do simple solution for just animate the default water texture?"
14. [09:34] Pet VFX: each pet has a Glow VFX folder (duplicate mesh, material Neon, recolor; lightning from "aura NPC" toolbox asset; separate glow meshes for parrot body and wings) and a Combat VFX folder (attack, hit, projectile effects from free flipbook assets).
15. [10:36] Create an "Enemy Spawn Locations" folder with invisible parts as enemy level zones.
16. [11:36] New Claude Project: document game design, pet info, animation IDs. Make shop icons in ChatGPT (dog, parrot, locked dragon); give Claude the Asset Manager image IDs.
17. [11:36] Prompt: "First, let's make the shop. When I interact with it, open the shop GUI... The shop should have button to buy and confirm." E to open; move gold display away from default Roblox buttons.
18. [12:36] Pet summoning and combat AI: describe dog model, VFX folders, animations, behaviour (follow, attack, spawn effects, combat effects). Fixes: auto-close shop after purchase, slow glow fade.
19. [13:36] Parrot: starting gold 2,000 for testing; flying height lowered from 8 to 4 studs.
20. [13:36] Enemies: R6-style zombies generated by Claude, level-scaled gold, 3 enemies per spawn location; reduce aggro distance.
21. [14:36] Update the project docs after sessions; later add treasure chests, pet HP regen/health bars, sounds, fix enemies launching into the sky.

## Exact settings and values
| Setting | Value | Notes |
|---|---|---|
| Meshy model type | Standard | Do not pick low poly first |
| Raw model triangles | about 250,000 | Too high |
| Remesh | Adaptive, low quality reduction, quads | Result about 3,000 triangles |
| Roblox mesh limit | about 10,000 triangles | As stated |
| Parrot remesh mistake | Fixed polygon count | Damaged texture, black patches |
| FBX export | Selected Objects on, Animation on, Path Mode Copy, Embed Media on, Scale 0.01 | |
| Studio import | Rig type Custom, load animations from FBX | Root motion differs from Blender |
| Starting gold | 2,000 (test), later 999,999 | |
| Parrot flight height | 8 studs lowered to 4 | |
| Enemies per spawn location | 3 | For performance |
| Aggro distance | reduced | Number not stated |

## Prompts and skills used
- Quoted in steps 1, 6, 8, 13, 17. Also: "Make another animation called idle..." and ask Claude to teach Blender animation switching.
- No named skills. Assets: aura NPC (Toolbox), flipbook particles, simulator shop test model.

## Gotchas and fixes
- Dog sitting in the reference art: ask for a four-legged standing pose.
- Walk cycle not looping: ask Claude to match last frame to first.
- Feet misaligned: IK bones on all four legs.
- Parrot wings too close to body: split wings into a separate mesh (imperfect); design wings spread out next time.
- Fixed remesh broke the texture: use Adaptive; repair with Healing Brush.
- Roblox ignores Blender root motion, so the parrot flies lower; reposition by script.
- Free shop model fell apart at runtime (many separate parts).
- Shop window stayed open hiding spawn VFX; glow faded too fast; enemies launched into the sky from colliding with each other; attack VFX missing at one point.

## Use it in our games
- The Meshy to Blender MCP to FBX pipeline is a way to make rigged pets for +1 pet simulators; aim for about 3,000 triangles (inferred).
- Include a plain standing pose with limbs and wings separated in the reference sheet before generating the 3D model.
- Keep a Claude Project design doc with animation IDs and folder structure, and update it after each session.
- Pet Glow VFX via duplicate neon mesh and Combat VFX folders is a cheap rarity-escalation pattern (inferred).
- Starting-gold test constants in config make tuning quick.
