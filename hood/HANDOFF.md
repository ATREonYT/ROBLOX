# Handoff for a Claude session connected to Roblox Studio

This is for a Claude Code session running on the owner's own computer and connected to Roblox Studio through Studio's built-in MCP server. The map is being built by a separate cloud session on the branch `claude/elegant-cannon-i9r37o`. This page says how to load and check that work in Studio without clashing with it.

## Load the latest build
1. `git pull` on branch `claude/elegant-cannon-i9r37o`.
2. Get the code into Studio, either way:
   - open `hood/places/HoodEvolution.rbxl`. It is a snapshot with the map already built, rebuilt after each finished pass;
   - or sync `hood/default.project.json` with Rojo (`rojo serve` in `hood/`), then build the map from the Command Bar or MCP `run_code`:
     ```lua
     require(game.ServerStorage.TheBlockV2).Build()
     ```
3. Press Play (MCP `start_stop_play`). You spawn in the warehouse lobby. The map sits at x = 2400.

## What is where (World 1, The Block V2)
- **Lobby hall** (spawn at the walkway cross, facing the Stage 1 door):
  - the armory on the stepped stand (east);
  - the themed shooting lanes (west);
  - the shoe-box dais (back centre);
  - the boosts pads (south-west corner);
  - leaderboards, WORLD 2, and the LIKE THE GAME / UPDATE SOON boards.
- **Stages 1–15, in five districts:** The Block, Corner Shop, The Alley, The Courts, The Yards. Each stage has a target wave; gate i opens with enough Power and the previous stage's wave cleared. The boss yard is stage 16.
- **Systems:**
  - guns (GunService, Armory.client);
  - ranges (LobbyService);
  - waves (WaveService, Waves.client);
  - goals (GoalService, Goals.client);
  - gates (StageService, Stages.client);
  - lighting preset HoodSun (`ServerStorage/HoodLighting`).
- **Reports** for each pass are in `reports/` at the repo root.

## Useful checks in Studio
- **Unit tests:** `require(game.ServerStorage.UnitTest.RunUnitTest)()` (Command Bar, edit mode).
- **Test cheat:** while playing, switch the Command Bar to Server and run:
  ```lua
  local D = require(game.ServerScriptService.HoodServer.DataService); local p = game.Players:GetPlayers()[1]; local d = D.get(p).Data; d.Rep = 30000; d.Cash = 30000; D.push(p)
  ```

## Avoid clashing with the cloud session
- `hood/src/ServerStorage/TheBlockV2.lua` is generated by the cloud session from its build pieces. Edits made to it directly get overwritten by the next build. Report map changes back, or make them only after the cloud session has handed the build source over.
- **In progress in the cloud session (2026-10-09):**
  - shoes and shoe boxes: 60 shoes worn on R15/R6 feet, plus pets-style followers; 10 boxes on the dais; open and equip;
  - re-laying the shooting lanes as a training plaza.
- The most useful things a Studio-connected session can do now:
  - playtest;
  - read the Output for errors (MCP `get_console_output`);
  - check how things look in real Studio lighting;
  - report back what is wrong.
