# Asset IDs

A decal ID does not load in an `Image` property, so code uses the image ID. Find one with `game:GetObjects("rbxassetid://<decal>")[1].Texture`.

## Style essentials

| Use | Name | Decal ID | Image ID | Notes |
|---|---|---|---|---|
| **Studs, the default** | Stud (Transparent) | 3014551680 | 3014551673 | 2 x 2 studs per image. Sheet: tile 50 x 46 at transparency 0.8. Cards and buttons: tile 48 x 48 at 0.55-0.78 |
| Studs, alternative | Universal Studs | 82666893993499 | 93033739647054 | 4 x 4 studs per image, every second stud has a raised R. Looks busy on white |
| **Light rays** | Light Rays | 135411666044030 | 101267161684975 | Spins behind heroes, crates and passes. Tint with `ImageColor3` |
| Shop icon | Shop Icon | 80349462371432 | 79989192301898 | Rail and window title |
| Rebirth icon | Rebirth icon | 15254183851 | 15254183826 | Rail and window title |
| Pointer | Pointer Stroke | 15724887327 | 15724887299 | Arrow cursor with its tip at the upper left, for tutorial hands |
