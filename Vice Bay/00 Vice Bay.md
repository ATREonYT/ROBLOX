# Vice Bay (GTA-style Miami RP)

Back to [[00 Start Here]] · [[README]]

A big, realistic Miami-inspired RP map. You start in the hood (west) and work your way east to downtown on the beach, the yacht marina and the islands. West over the Coral Causeway is the lush Coral County suburb.

## Notes
- [[Map Bible]]: districts, coordinates, roads, all 98 POIs, properties, the stock market, setup checklist.
- [[Map Building Lessons]]: everything learned so far, from this vault's research plus the Vice Bay build (what broke and how it was fixed).
- [[Build System]]: how the map is generated by code (VBLib), the rebuild order, and the rule that keeps work from being lost again.
- [[Realistic Texture Plan]]: which of the 152 downloaded CC0 textures in `realistic-textures/` go where in Vice Bay.

## Source code (in `Vice Bay/src/`)
- `VBLib.core.lua` + `VBLib.buildings.lua`: the builder library (early version; the newer generators are listed in [[Build System]] and get re-added during the rebuild).
- `StockMarket.server.lua`: the VBX stock exchange server (ServerScriptService).
- `StockTradingUI.client.lua`: the trading window (StarterPlayerScripts).

## Status (2026-11-01)
- The first full build (about 49k parts, 98 POIs) lived only in the cloud place **hood life** (placeId 103048958765318). Studio closed before it was saved, and Roblox had an outage ("Failed to fetch place info"), so that build is probably lost.
- **Now building in Miami Trap Life : North Remastered** (placeId 95405231186296). Use File → Save to File As → `MiamiTrapLife.rbxl` as a local backup, plus publish.
- **Rebuild plan (old):** open a new Baseplate, save it as `ViceBay.rbxl` (a local file), then rebuild section by section with **Cmd+S after each section**. Every build step is also saved as a `.lua` file in `Vice Bay/src/build/`, so the map can be regenerated from the vault at any time.
