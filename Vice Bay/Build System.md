# Build system (how Vice Bay is generated)

Back to [[00 Vice Bay]] · [[Map Building Lessons]]

The map is generated by Luau run in Studio (Edit mode, through the Studio MCP or the Command Bar) and then **saved into the place**. Nothing is generated at runtime.

## Golden rules
1. Every build chunk that is run also gets saved as a numbered file in `Vice Bay/src/build/` (e.g. `03_roads.lua`). The vault is the source of truth; the place is the output.
2. After each section, **Cmd+S** (local `ViceBay.rbxl`). Publish to the game when Roblox is up.
3. Keep chunks small and `task.wait()` between batches (about 1,000 parts), or Studio freezes and the MCP drops.
4. Load the library with `local L = require(game.ServerStorage.VBLib:Clone())` so edits aren't hidden by the require cache.

## Coordinates
- North = −Z, east = +X. Ground level `L.G = 2`. Water surface y = −4.
- Mainland x −2048…1460, z −1152…652 (+ port strip to z 1140). Beach x 1460…1600. Glades x −2050…−1800. County x −4900…−2320.
- All district coordinates are in [[Map Bible]].

## Library API (`ServerStorage/VBLib`)
**Basics**
- `L.P(parent,size,cf,color,mat,var,opt)` makes a part. Every part is anchored, smooth-surfaced and CanTouch off, and small parts get CastShadow off.
- `L.B(parent,cf,x,y0,z,sx,sy,sz,...)`: a box whose bottom sits at `y0`, in local space of `cf`.
- `L.Cyl`, `L.Ball`, `L.W` (wedge), `L.text`, `L.sign`, `L.folder`, `L.model`, `L.asset(name,parent,cf,scale)` (clones from `ServerStorage/VBAssets`).
- RNG: `L.seed`, `L.r`, `L.ri`, `L.pick`, `L.chance`.

**Roads**
- `L.net(lines, river)` takes polylines, cuts them at the river (bridges optional), intersects them pairwise, snaps nodes within 14 studs, prunes stubs and adds cul-de-sacs.
- `L.buildRoads(parent, net, folder)` builds asphalt per edge, sidewalks trimmed at junctions, markings, crosswalks, poles with Beam wires, lights, palms and bend disks.
- `L.roadDetails(parent, net)` adds curbs, red curbs, tar patches, storm drains, manholes, hydrants, trash cans, weeds, stop signs, multi-head traffic lights, lane arrows and hatch boxes.
- `L.road3D(parent, points, width, {barriers=true})` builds hill roads and bridges with jersey barriers.
- Road styles:
  - HOOD: worn asphalt, sw 9, one faded line, poles, cul-de-sacs
  - HOODA: double yellow, sw 10
  - HAB / HABA: clean, edge lines, brick crosswalks
  - WYN / WYNA: pavers, bike lanes
  - DT: sw 14, lanes, modern lights, brick crosswalks
  - BLVD: 12-wide palm median
  - PORT
  - County: BLVD / MAIN / CR / RES

**Lots**
- `L.fill(folder, net, chooser, filter)` walks along road edges and places generators facing the road.
- It skips a lot if the box at road height overlaps anything in Roads / Buildings / Reserved / Landmarks / Highway / River / Rail / CountyRoads / CoralCauseway, or if the ground is water.

**Generators**
- Buildings: house, shop, bays, stilts, walkup, warehouse, church, emptyLot, condoBoard, midrise, tower, dtTower, artdeco, flhouse, stripmall, mansion.
- `supertall(kind)` with kind = twist / stepped / twin / round / slant.
- Boats: yacht, sailboat, boat.
- Interiors: shell + `furnish(style)` (lux / normal / poor), elevator.
- Structures: bridge, dock, canopy, court, parking, pad.
- Props: foodtruck, picnic, stringLights, mural, policeCar, ambulance, graffitiImg, bars, weeds, stopSign, trafficLight, palm, tree, bush, car, hydrant, trashcan, dumpster, bench, fence.
- Helpers: roof, sideWin, window, grit, `groundY` (raycast from y 400).
- `L.poi(pos, category, name, attrs, opts)` makes an invisible part with a ProximityPrompt, a map icon and CollectionService tags.

## Rebuild order
1. Lighting + streaming settings (`LightingStyle = Realistic`, `PrioritizeLightingQuality = true`).
2. MaterialVariants (from the realistic texture set, see [[Realistic Texture Plan]]) and cleaned assets (`VBAssets`).
3. Terrain: ocean, beach, river, glades, county hills.
4. Road network + details (save the lines in a ModuleScript `VBRoadLines`, not `_G`).
5. Hood → rail + I-95 → Habana / Wynwood → downtown + supertalls → Stock Exchange → beach → marina → islands (only Star Island bridged) → port → Coral County + Coral Heights.
6. Interiors (penthouses, villas, houses) + elevators.
7. Vegetation pass, clutter pass, POIs, scripts (StockMarket, PropertyElevators, trading UI).
8. Performance pass: building Models, SLIM LOD, CastShadow on small parts, part count check.

## Pipeline: vault to Studio (2026-11-01)
1. Source lives in `Vice Bay/src/lib/*.lua` (Core, Props, Roads, Build) and `Vice Bay/src/build/*.lua` (lines, 01_terrain, 02_roads, 03_hood, ...).
2. Copies sit in `realistic-textures/downloaded/_vbsrc/`, served by `python3 -m http.server 8799 --bind 127.0.0.1` (run in that folder).
3. In Studio, `ServerStorage/VBRun` fetches them (it turns HttpEnabled on just for the fetch), writes ModuleScripts into `ServerStorage/VB` and `ServerStorage/VBBuild`, and runs them:
   ```lua
   local R = require(game.ServerStorage.VBRun:Clone())
   R.run("lines"); R.run("02_roads"); R.run("03_hood")
   ```
4. Texture ids are stored in `ServerStorage/VBTextureIds` (raw upload results). The MaterialVariants are in `MaterialService/Realistic`.
